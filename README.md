# GameVault 🎮

GameVault — это премиальный игровой веб-портал, разработанный на фреймворке Django. Главный акцент в проекте сделан на визуальную составляющую и пользовательский опыт (UX). Признан лучшим проектом на потоке в Proweb благодаря глубокому, атмосферному дизайну.

## Фичи и визуал
- **Динамическая атмосфера:** Фон каждой страницы подстраивается под контент. Цветовая палитра и арт меняются в зависимости от открытой игры, погружая пользователя в нужную атмосферу с помощью полупрозрачных слоев.
- **Анимация виньетки:** Реализован сложный эффект фокусного круга (фонарика). Яркий центр плавно перемещается по экрану (чистый CSS/JS), создавая эффект живого пространства и глубины.
- **Современный UI:** Использование Glassmorphism (стеклянного морфизма) для карточек, чтобы они гармонично ложились поверх игровых артов.
- **Микроинтеракции:** Плавное появление элементов при скролле (AOS) и продуманные hover-эффекты.

## Основной функционал
- **Каталог игр:** Детальные страницы с системными требованиями, трейлерами и скриншотами.
- **Модификации:** Раздел для просмотра и скачивания модов к играм.
- **Блог:** Раздел с новостями игровой индустрии.
- **Социалки:** Регистрация, личные профили, система комментариев под играми и новостями.
- **Поиск:** Умный сквозной поиск по играм, модам и статьям.

## Технологии
- **Backend:** Python, Django, SQLite
- **Frontend:** HTML5, CSS3 (Gradients, Animations), JavaScript, Bootstrap, Swiper.js, AOS

## Архитектура
В проекте реализована грамотная декомпозиция данных (отдельные модели для игр, новостей, системных требований, комментариев). Присутствует строгая проверка прав (например, при удалении комментариев), а глобальный поиск оптимизирован с использованием `Q` объектов.
